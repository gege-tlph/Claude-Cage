Cage lite 第一个发行版，基于上游 Claude Cage 0.2.0，只提供 Windows 版（Windows 10 22H2 或 Windows 11，x64）。

## 安装

1. 下载 `Cage-0.2.1-windows-amd64-setup.exe` 并运行。
2. 在安装选项页勾选“信任 Cage lite 发布者证书”（默认已勾选），Windows 弹出确认时选“是”。不勾选也能使用，但 Windows 会显示发布者未知，应用内更新也无法自动安装。
3. 已经装了上游 Cage 的，直接覆盖安装，环境和数据都会保留。

安装时没有勾选，或用的是静默安装，可以手动导入本页附带的 `cage-lite-signing.cer`：

```powershell
Import-Certificate -FilePath .\cage-lite-signing.cer -CertStoreLocation Cert:\CurrentUser\Root
```

导入这张证书，表示你信任用它签名的程序。这张证书只能用于代码签名。

## 与上游 0.2.0 的主要不同

产品与更新
- 产品名改为 Cage lite。应用内更新从本仓库获取，只接受 Cage lite 的签名。
- 界面只保留简体中文和英文。

首次设置
- 代理页可以测试和修改加密 DNS（#815）。
- 公共 DNS 备用默认开启（#470）。
- 删除过环境存储、或存储无法使用时，可以重新选择存储位置或重建环境（#453 #846）。
- Windows 上 cloud-init 监视不再提前、重复报告成功（#828）。
- 启动后立即停止环境不再要等满 3 分钟。
- 引导界面不再跳动。

环境
- 客机里的用户名以外的固定标识改为中性名称：服务、程序路径、配置目录、环境变量、声卡名称（#605）。旧环境在第一次启动时自动迁移，旧目录保留。
- 运行中修改了下次启动才生效的设置时，会提示重启。
- 高分屏上“优先流畅”默认关闭，客机浏览器和 Desktop 画面更清晰。
- 只改偏好设置时，保存不再重启环境。
- 客机浏览器不再显示 unsupported command-line flag 提示条。
- 终端里可以直接运行 `cage`，安装器会把它加入用户 PATH（#861）。

Claude 账号与 Desktop
- 授权页加载慢时，登录窗口不再自动关闭，即“授权 Code”后只看到 Bing 的问题（#791）。
- 默认 Desktop 可以和独立实例并排显示（#883）。
- 托管账号继承 `~/.claude/settings.json` 里安全的 env 开关（#834）。
- 隐私打码：一个开关同时隐藏出口 IP、位置和账号邮箱（#804 #836）。
- 手机接续连接官方中继前需要确认（#740）。

代理
- 可以把可信的本机代理端口作为代理链第一跳（#595）。
- 本机代理导入能识别 SakuraCat，并提示改用订阅（#892）。
