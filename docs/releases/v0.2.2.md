Cage lite 0.2.2，只提供 Windows 版（Windows 10 22H2、Windows 10 LTSC 2021 或 Windows 11，x64）。

## 安装

1. 已装 0.2.1 的，可以在应用内更新，也可以下载 `Cage-0.2.2-windows-amd64-setup.exe` 覆盖安装，环境和数据都会保留。
2. 新安装的，在安装选项页勾选"信任 Cage lite 发布者证书"（默认已勾选），Windows 弹出确认时选"是"。也可以手动导入本页附带的 `cage-lite-signing.cer`：

```powershell
Import-Certificate -FilePath .\cage-lite-signing.cer -CertStoreLocation Cert:\CurrentUser\Root
```

## 与 0.2.1 相比

系统
- 支持 Windows 10 企业版 LTSC 2021 和 IoT 企业版 LTSC 2021（19044）。同一版本号的普通 21H2 已停止支持，仍不能安装。

终端
- 输出很多时终端不再被断开；网络中断后自动重连，只补断开期间缺的输出，不再整段重放。
- emoji 按两格显示，后面的文字和光标不再错位。
- 程序在终端里输出的链接，确认后在环境里的浏览器打开。以前点了没有反应。
- 重开没有记下账号身份的旧会话时，不再误报"登录已在其他终端更改"（#800）。

网络与代理
- 内置代理在运行中退出或不再响应时，自动重新应用当前节点，并在完整检查通过后恢复外网。
- 新增"局域网直连"（设置 → 网络与代理）：填一个私有网段后，外网放行期间环境可以直接访问其中的 NAS、开发服务器等。不经过代理节点，本机自己的地址不开放。
- 用系统自带的"宽带连接"（PPPoE）拨号上网时，代理绑定到这条拨号连接（#745）。
- 主机内存紧张时，自动联网重检最多推迟 2 分钟，不再一直不重检（#955）。
- 网卡失效、切换或恢复后，代理核心自动重绑并清掉失联状态（#781 #951）。
- 订阅下载遇到 5xx、限流或连接中断时自动重试；重定向时不再把带 token 的订阅地址发给下一个服务器。
- 外网门槛的判定不再占着全局锁，环境里的网络连接不再排队。
- 出口探测超时放宽，失败原因更具体，不再出现"失败失败"（#25）。
- FlClash（含 oixCloud 版）自动发现不再把应用状态文件当成配置，并标出当前选中的订阅（#943 #954 #957）；Clash Neo、Clash Verge Ninja 的特殊节点导入时说明兼容性（#790 #837）。
- 修复客机 DNS 转发和引导 DNS 的若干问题（#748 #771）；软路由宿主没有硬件上行网卡时，能识别 Hyper-V 虚拟网卡（#742）。

浏览器与 Claude Desktop
- 新建标签页时网页加载慢，不再误报"客机浏览器暂时无法连接"（#948）。
- 授权页加载慢时不再关掉授权标签（#791）。
- Windows 上 Claude Desktop 连续拼音输入不再丢首字母（#940）。
- 独立 Desktop 登录后回到发起授权的那个实例（#820）。
- WebView 白屏或无响应时，可以从菜单重建或重载（#684）。
- 可以删除包括默认实例在内的任意 Desktop 实例，只要不是最后一个（#899）。
- 更新 Claude Desktop 期间，联网许可照常续期（#897）。

Claude 账号与手机
- 只登录了 Desktop、还没授权 Code 的账号，不再被额度检查标成"身份已改变"（#970）。
- 一台电脑可以同时配对多台手机，并在设置里分别管理（#927）。
- 手机上远程 Desktop 可以触摸滚动（#822），消息发送和恢复时自动重连。

插件
- 插件可以提供可拖动、可收起的半透明浮窗视图（#879）。插件市场里使用浮窗的插件现在可以安装和更新。
- 插件更新失败时的报错不再一闪而过；不兼容的更新不能点（#946）。

环境
- 虚拟机进程孤立时，状态显示"未完全停止"，"停止环境"可以点（#508）。
- 配置目录太深时，启动前就提示路径太长（#913）。
- Windows 首次初始化时可靠地判断 cloud-init 已完成（#782）。
- 首次设置和存储选择不会把环境目录放进 AppData 或临时目录（#676）；清理残留虚拟机状态更可靠（#839）。
- 主题同步失败不再挡住环境启动（#950）。
- 麦克风连接失败时逐次退避，不再每 2.5 秒重连（#928）。
- 安装器在系统 LIB 环境变量失效时也能完成安装（#958）。

安全
- WebSocket 库升级，修复 GO-2026-6278（客户端掩码使用弱随机数）。
- 诊断信息脱敏不再在反引号处截断路径（#936）。
